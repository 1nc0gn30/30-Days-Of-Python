## 💻 Local Development
### 📋 Prerequisites
- Node.js 20+
- npm 10+

### ⚙️ Setup
```bash
npm install
cp .env.example .env.local
```

Add your key in `.env.local`:
```env
GEMINI_API_KEY="your_key_here"
```

### 🚀 Run
```bash
npm run dev
```
App runs on `http://localhost:3000`.

## 🔨 Build and Quality
```bash
npm run lint
npm run build
npm run preview
```
